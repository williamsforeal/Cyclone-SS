# Static Ad Generator

Generate 40+ production-ready static ad images for any brand — from brand research to finished creatives — entirely inside Claude Code.

## Critical Rules

- Never fabricate brand details (hex codes, fonts, founding stories). Every claim in the Brand DNA must come from a web search hit or a fetched page.
- Never generate without product reference images for templates that include the actual product. The whole point of the FAL `edit` endpoint with image refs is to render the real packaging, not a guess.
- Always cap initial test runs at 5 prompts before scaling to 40+. Per-image cost adds up fast.
- Always confirm `FAL_KEY` is set as an env var before calling the script. Failures mid-run are expensive in time.
- Coaches gate execution. Output is a draft for review, not a direct-deploy creative batch.

## Prerequisites

- `FAL_KEY` env var set
- Python with `requests` installed
- Product images dropped in `<brand-folder>/product-images/` BEFORE running
- A library of template prompts (see `references/template-prompts.md`)

## Folder Structure

```
~/brands/{brand-name}/
├── product-images/          # Drop product PNGs/JPGs/WebPs here first
├── brand-dna.md             # Generated by Phase 1
├── prompts.json             # Generated by Phase 2
├── generate_ads.py          # Image gen script (Phase 3)
└── outputs/
    ├── 01-headline/
    ├── 02-offer-promotion/
    └── ...
```

## Phase 1 — Brand Research & DNA Generation

When the user provides a brand name + URL, run reverse-engineering research:

1. **External research** (web search):
   - Design agency / case studies / rebrand history
   - Brand guidelines PDF / press kit / style guide
   - Typography (`"what font does [Brand] use"`)
   - Colors (`"[Brand] hex codes"`)
   - Packaging photography
   - Current Meta Ads Library activity
   - Founding story / mission

2. **On-site analysis** (fetch brand URL):
   - Voice & tone — 5 distinct adjectives from hero copy
   - Photography style — lighting, color grading, composition
   - Typography — headline weight, body weight, distinctive treatments
   - Color application — primary vs accent, CTA color
   - Layout density, packaging detail

3. **Competitive context** (2-3 direct competitors):
   - How does the target brand differentiate visually?

4. **Compile to `brand-dna.md`** with sections:
   - Brand Overview
   - Visual System (fonts, colors, CTA styles)
   - Photography Direction
   - Product Details
   - Ad Creative Style
   - **Image Generation Prompt Modifier** — 50-75 word paragraph prepended to every ad prompt

## Phase 2 — Prompt Generation

Read `brand-dna.md` and `references/template-prompts.md` (40 templates with `[BRACKETED]` placeholders). For each template:

1. Fill every placeholder with brand-specific detail from the DNA
2. Tag with correct aspect ratio
3. Tag whether it needs product reference images (`needs_product_ref: true/false`)
4. Write all to `prompts.json` in the brand folder

## Phase 3 — Image Generation

Run `generate_ads.py`. The script:

1. Reads `prompts.json`
2. Uploads `product-images/*` to FAL storage → URLs
3. For each prompt:
   - If `needs_product_ref: true` → call FAL `edit` endpoint with reference images
   - Else → call FAL text-to-image endpoint
4. Downloads outputs into `outputs/<template-num>-<template-name>/`
5. Writes per-image `prompt.txt` next to each output
6. Generates `outputs/gallery.html` for easy review

> The `generate_ads.py` script is not yet authored. See `references/script-spec.md` for the spec when implementing.

## Failure Modes + Fixes

| Symptom | Cause | Fix |
|---|---|---|
| FAL 401 | `FAL_KEY` not set or invalid | `export FAL_KEY="..."` in shell |
| Product image not rendered correctly | Photo too low-res or wrong angle | Re-shoot at higher res; multiple angles |
| Brand colors off in output | Hex codes wrong in DNA | Re-verify hex codes from source; update DNA |
| Text rendering garbled | Headline too long for aspect ratio | Shorten copy; test on 1:1 first |
| Cost overrun | Running 40+ prompts unsupervised | Cap at 5 prompts per test batch first |

## What This Skill Does NOT Do

- Does not upload finished ads to Meta — that's a separate step.
- Does not log to Airtable — pair with `airtable-ops` after review.
- Does not generate video — that's `seedance-ugc-ads`.
- Does not write ad copy (headlines, body text) from scratch — that's `meta-hook-writer` (deferred). Copy must be provided as input to the templates.
