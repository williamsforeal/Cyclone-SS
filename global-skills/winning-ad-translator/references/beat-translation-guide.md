# Beat Translation Guide

Cialdini lever mapping per beat + brand archetype voice rules. Read this before generating any translation.

---

## Beat Lever Map

| Beat | Cialdini Lever | Execution note |
|---|---|---|
| Hook | Social proof (flipped negative) | "Most [identity group] are doing X the wrong way." Locks in identity before problem. |
| Problem | Authority + scarcity of time | Name the exact inferior method they've tried. Triggers safety memory or time-loss frustration. |
| Solution + Proof | Consistency + authority | Show the outcome BEFORE claiming it. Demo first, voiceover second. |
| Offer Reveal | Reciprocity | Bundle flash — each item named individually. Bonuses feel like gifts. |
| Close | Commitment + loss aversion | Risk reversal (removes friction) + calendar deadline (creates urgency). In that order. |

## Archetype Voice Rules

### Craftsman / Guide (Pit Smith)
**Voice profile:** Rugged, direct, practical, masculine, summer-ready. No jargon. No hype. No fake urgency.

**Do:** "Most guys clean their grill the hard way." / "One pass. Done." / "Start every cookout ready."
**Don't:** "Mind-blowing results!" / "Revolutionary technology!" / "Everyone is switching to this!"

**Identity lock phrases:** guys, pitmasters, backyard, cookout, grate, season
**Banned words/phrases:** "Whoever invented this deserves a raise", "I still can't believe the discount", "shed-proof" (unverified), "dishwasher safe" (unverified), "bristle-free" (unverified)

**Close pattern:** Risk reversal first ("60-Day Pitmaster Promise"), then calendar deadline ("ships for Father's Day"), then "link in bio" — never naked discount urgency.

---

### Sage / Wellness Guide (Abundria / Palm Aura)
**Voice profile:** Calm, warm, refined, trustworthy. Not medical. Not clinical. Not aggressive.

**Do:** "Your hands carry the work of your day." / "15 minutes of warmth. Daily ritual." / "Backed by a 60-day relief promise."
**Don't:** "Cures pain!" / "Clinically proven!" / "Doctors recommend!" (unverified)

**Identity lock phrases:** hands, daily ritual, warmth, relief, calm, wellness, recovery
**Banned words/phrases:** Any clinical or medical claim without verification, "miracle", aggressive pain descriptors

**Close pattern:** Emotional transformation promise + 60-day relief guarantee + "Try risk-free."

---

### Warrior / Explorer (Cold Plunge / Future Products)
**Voice profile:** Bold, achievement-oriented, direct. Challenges the reader to level up.

**Do:** "Most people won't do this. That's the point." / "Cold exposure isn't comfortable. That's why it works."
**Don't:** Clinical promises, fake softness, wellness-washing

## Competitor-to-Brand Translation Table

When you encounter supplier-listing language from a competitor ad, replace it:

| Supplier slop | Brand translation |
|---|---|
| "Effortless cleaning" | "Cuts grill cleaning from 20 minutes to 5" [VERIFY] |
| "Dishwasher safe brush heads" | "60-Day Pitmaster Promise" |
| "Shed-proof bristles" | "Father's Day gift he'll actually use" |
| "Amazing results" | Show the clean grate — let the demo be the claim |
| "Order now while supplies last" | "Order by [DATE] for Father's Day delivery" |
| "Whoever invented this deserves a raise" | "Most guys clean their grill the hard way." |

## Beat Compression Rules by Cut Length

### 15s Meta Feed
Beats 1-2-3-4-5 compressed to ~3s each. Beat 3 (Solution+Proof) gets the most time. Beat 6 removed.
Pacing: Hook density over depth. Every second must work.

### 22s Reels Extended
Beats 1-2-3-4-5 with Beat 3 expanded to 6-8s. Add one secondary proof point.
Pacing: Hook + demo + offer. Cut is still conversion-optimized, not storytelling.

### 39s TikTok Native
Full 6-beat structure. Beat 6 (Depth/Scenarios) inserted between Beat 3 and Beat 4.
Pacing: Storytelling. Allows setup before demo. Works on TikTok's longer attention window.

## Asset Reuse Rule

All three cuts should use the **same visual assets**. Only pacing and voiceover change.

This:
- Isolates cut length as the single test variable
- Reduces Higgsfield generation cost by ~66%
- Makes creative performance data clean and comparable
