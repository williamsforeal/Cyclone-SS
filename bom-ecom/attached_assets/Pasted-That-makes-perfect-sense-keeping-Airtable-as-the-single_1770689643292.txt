```jsx
import React from 'react';
import { ExternalLink, ArrowRight } from 'lucide-react';

const TopCandidatesTable = ({ candidates }) => {
  // Helper to color-code scores

    if (score >= 80) return 'text-green-400 border-green-900 bg-green-900/20';
    if (score >= 50) return 'text-yellow-400 border-yellow-900 bg-yellow-900/20';
    return 'text-red-400 border-red-900 bg-red-900/20';

  return (
    <div className="w-full mt-6 bg-[#13141c] border border-gray-800 rounded-xl overflow-hidden shadow-sm">

      </div>

      <div className="overflow-x-auto">
        <table className="w-full text-left text-sm text-gray-400">

            <tr>
              <th className="px-6 py-3">Product</th>
              <th className="px-6 py-3">Niche</th>

                    {item.imgUrl ? <img src={item.imgUrl} alt="" className="w-full h-full object-cover" /> : null}
```

### 3. How to wire this in n8n (The Backend)

Since you already have the "Static Scaler" base:

1. **New Workflow:** Create a simple endpoint (e.g., `GET /top-candidates`).
2. **Airtable Node:**
* **Resource:** `Record`
* **Operation:** `List`
* **Filter:** Sort by `Score` (Descending). Limit to 5 or 10 records.


3. **Code Node (Transform):** Map your Airtable columns to the clean JSON format I wrote above (renaming `fields.Score` to `score`, etc.).
4. **Respond to Webhook Node:** Return that JSON array.

This keeps your frontend dumb (just displaying data) and your backend smart (sorting and filtering in Airtable/n8n).
