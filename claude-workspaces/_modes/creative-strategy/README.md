# Mode — Creative Strategy

For building the foundational strategy artifacts every other mode depends on.

## When to use this mode

- Onboarding a brand-new brand to the workspace family
- Refining strategy for an existing brand after performance data is in
- Auditing why creative isn't converting (often a strategy problem)
- Periodic refresh (every 1-3 months) of avatars and beliefs

## What loads with this mode

Skills:
- `brand-dna-builder` — Identity, USP, voice, archetype, what-it's-not
- `storybrand-framework` — Customer-as-hero BrandScript (all 7 elements)
- `necessary-beliefs` — 5-7 belief gates that must be installed to buy
- `avatar-builder` — Specific personas with current/target beliefs
- `eugene-schwartz-awareness` — 5-level matrix per avatar

## Output structure

Per brand, this mode produces:

```
brands/<brand>/
├── brand-pack.md          ← Brand DNA + visual identity (from brand-dna-builder)
├── brandscript.md         ← StoryBrand 7-element script (from storybrand-framework)
├── necessary-beliefs.md   ← 5-7 belief gates (from necessary-beliefs)
├── avatar-sheet.md        ← 2-3 avatars (from avatar-builder)
└── awareness-matrix.md    ← 5-level matrix per avatar (from eugene-schwartz-awareness)
```

These artifacts are read by every other mode. Build them well; everything downstream gets easier.

## Coach gate

All 5 artifacts go through coach review BEFORE downstream modes start producing ads, content, or PDPs from them. A bad avatar produces dozens of off-target ads.
