# Mode — TikTok Slideshow

For building TikTok slideshow content as a system — hook bank → slideshow factory → image collections → posting cadence.

## When to use this mode

- Standing up TikTok organic for a new brand
- Building a slideshow content engine that runs continuously
- Refreshing a depleted hook bank
- Converting winning paid hooks into organic slideshow tests (or vice versa)

## What loads with this mode

Skills:
- `hook-bank-generator` — Generate 20-25 hooks across 7 categories
- `slideshow-builder` — Convert one hook to a full 6-8 slide deck

## Required inputs

- Brand pack (active brand)
- Avatar(s)
- Offer (informs soft CTA)
- Image collections OR plan to generate via Higgsfield

## Coach gate

Per AI Com Academy — coach review on hook banks BEFORE building slideshows from them. Slideshow drafts also go through coach before posting (especially for compliant before/after framings).

## Outputs go to

- `outputs/hook-bank-<brand>.md`
- `outputs/slideshows/<hook-slug>-<date>.md`
- `outputs/image-collections/<niche>.md`
- `plans/posting-cadence-<brand>.md`
