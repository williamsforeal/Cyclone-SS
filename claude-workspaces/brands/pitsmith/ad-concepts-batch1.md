# BATCH 1 LAUNCH STRUCTURE
# ═══════════════════════════════════════

## Campaign Setup (Per Course Methodology)
- **Structure:** 1 CBO campaign
- **Budget:** $50/day
- **Ad sets:** 1 (Advantage+ audience, US, 25+)
- **Gender targeting:** Test all genders first — gift buyer is female, other avatars male
- **Media upload:** Flexible format — upload all 5 statics + 2 videos as assets
- **Primary text:** 3 variants per ad set (pull from statics 1, 2, 5 — most distinct)
- **Headlines:** 3–5 variants
- **Ad names:** Use avatar code → "B1-S01-GiftBuyer" / "B1-V01-WifeUGC"

## Kill/Scale Thresholds (At $99.99 price, $43 working margin)
```
CPA Target (profitable):     $25–35
CPA Acceptable (break-even): $43
CPA Kill trigger:            $86 (2× break-even — per course chapter 7.5)
CTR Watch (minimum):         1.0% (flag below this — creative problem)
Hook Rate (video):           25%+ (if below, hook needs rewrite)
Hold Rate (video):           40%+ at 3 sec (if below, open 2 sec not working)
```

## Post-Launch Decision Tree (Day 3–5)
```
IF CPA < $35 on any creative → increase budget 20%, hold 48 hrs
IF CTR > 2% but no purchases → landing page issue, not creative
IF hook rate < 20% on video → rewrite hook, same concept
IF statics outperform videos → double static batch, test 5 more angles
IF gift buyer outperforms all → build 3 more gift-angle statics immediately
```
