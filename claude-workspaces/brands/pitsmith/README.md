- **Voice:** rugged, practical, confident, summer-ready. No formality, no clinical, no novelty.

- **Colors:** `pit_white #F8F6F1` / `charcoal_black #171717` / `cast_iron_navy #10233F` / `ember_red #B7372F` / `ash_white #ECE8E0` / `steel_gray #68707A` / `brass_heat #C79B52`
